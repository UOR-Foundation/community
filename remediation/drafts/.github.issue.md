## Problem

UOR-Foundation/.github does not yet meet the repository standards of UOR-Foundation/.github (STANDARDS.md and GOVERNANCE.md 6.1, 6.2 and 11), observed at `92da114114fc` of `main`. It carries no tier tag. The uor-repo-tier app proposes Tier 3 (docs, websites and presentation) from its use case, docs: README: "the main entry point for the UOR Foundation on GitHub"; it holds the governance documents. Maintainers who record another tier tag change every requirement below; the change set is re-projected from it.

## Proposed Solution

### In a pull request

- Add LICENSE with the SPDX MIT text (GOVERNANCE.md 13: MIT is the default), copyright 2026 The UOR Foundation

### Repository settings an Organization Owner applies

- Require a pull request before merging to the default branch
- Require at least 1 approving review
- Require status checks to pass before merging
- Block force pushes to the default branch
- Add topic uor
- Add topic uor-foundation
- Add topic tier-3-presentation
- Add topic active: it is in normal development, its last commit 2026-04-01 (GOVERNANCE.md 11)
- Add topic governance: README: "the main entry point for the UOR Foundation on GitHub"; it holds the governance documents
- Add topic documentation: README: "the main entry point for the UOR Foundation on GitHub"; it holds the governance documents

Topics: `active documentation governance tier-3-presentation uor uor-foundation`. The ruleset is `governance-6.2-t3` in `remediation/apply-settings.sh` of UOR-Foundation/community.

### For the maintainers to confirm

- **check-contexts**: Which status checks must pass? The owner's settings script requires the jobs a pull request reports from workflows that run on every pull request.
- **ci**: Which CI workflow should it run? The repository states no test command the remediation can run.
- **copyright-holder**: Is the copyright holder the drafted LICENSE names right?
- **domain**: Are the proposed Domain topics all that apply?
- **status**: Is the proposed status right (active, maintenance or deprecated)?
- **tier**: Is the proposed tier right?

## Alternatives Considered

- .github is not in the preferred uor-{domain}-{function} form; a new name is a maintainer decision
- 27 of 27 default-branch commits are not Conventional Commits; history is not rewritten, so the naming app cannot find the repository conformant
- .github is not lowercase and hyphen-separated, and no lowercase rename is (GitHub requires the name .github for organization health files)
