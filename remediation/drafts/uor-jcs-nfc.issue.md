## Problem

UOR-Foundation/uor-jcs-nfc does not yet meet the repository standards of UOR-Foundation/.github (STANDARDS.md and GOVERNANCE.md 6.1, 6.2 and 11), observed at `303591128094` of `main`. It carries no tier tag. The uor-repo-tier app proposes Tier 1 (core framework and critical specs) from its use case, spec: description: "Specification, reference implementation, and conformance suite for UOR's RFC 8785 JCS + Unicode NFC JSON digest context". Maintainers who record another tier tag change every requirement below; the change set is re-projected from it.

## Proposed Solution

### In a pull request

- Add .github/CODEOWNERS naming @afflom (GOVERNANCE.md 6.1)
- Add the CI workflow .github/workflows/conformance.yml: the conformance run README.md states, under CPython 3.12 (Unicode 15.0.0, SPEC.md 1.3) (GOVERNANCE.md 6.1)

### Repository settings an Organization Owner applies

- Require a pull request before merging to the default branch
- Require at least 2 approving reviews
- Require status checks to pass before merging
- Block force pushes to the default branch
- Add topic uor
- Add topic uor-foundation
- Add topic tier-1-core
- Add topic active: it is in normal development, its last commit 2026-09-11 (GOVERNANCE.md 11)
- Add topic cryptography: description: "Specification, reference implementation, and conformance suite for UOR's RFC 8785 JCS + Unicode NFC JSON digest context"
- Add topic protocol: description: "Specification, reference implementation, and conformance suite for UOR's RFC 8785 JCS + Unicode NFC JSON digest context"
- Add topic python: GitHub's primary language is Python, which Linguist names python

Topics: `active cryptography protocol python tier-1-core uor uor-foundation`. The ruleset is `governance-6.2-t1` in `remediation/apply-settings.sh` of UOR-Foundation/community.
