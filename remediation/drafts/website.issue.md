## Problem

UOR-Foundation/website does not yet meet the repository standards of UOR-Foundation/.github (STANDARDS.md and GOVERNANCE.md 6.1, 6.2 and 11), observed at `1008c3b09892` of `main`. It carries no tier tag. The uor-repo-tier app proposes Tier 3 (docs, websites and presentation) from its use case, website: the uor.foundation website. Maintainers who record another tier tag change every requirement below; the change set is re-projected from it.

| Decision app | Observed | After the change set |
|---|---|---|
| uor-repo-files | missing-file | conformant |
| uor-repo-protection | unobserved | conformant |
| uor-repo-standards | untagged | conformant |
| uor-repo-naming | nonconforming | blocked |

## Proposed Solution

### In a pull request

- Add LICENSE with the SPDX MIT text (GOVERNANCE.md 13: MIT is the default), copyright 2025 The UOR Foundation

### Repository settings an Organization Owner applies

- Require a pull request before merging to the default branch
- Require at least 1 approving review
- Require status checks to pass before merging
- Block force pushes to the default branch
- Add topic uor
- Add topic uor-foundation
- Add topic tier-3-presentation
- Add topic active: it is in normal development, its last commit 2026-11-13 (GOVERNANCE.md 11)
- Add topic documentation: the uor.foundation website
- Add topic visualisation: the uor.foundation website
- Add topic typescript: GitHub's primary language is TypeScript, which Linguist names typescript

Topics: `active documentation tier-3-presentation typescript uor uor-foundation visualisation`. The ruleset is `governance-6.2-t3` in `remediation/apply-settings.sh` of UOR-Foundation/community.

### For the maintainers to confirm

- **branches**: Which of its non-conforming branches are renamed and which deleted?
- **check-contexts**: Which status checks must pass? The owner's settings script requires the check runs reported on the default branch.
- **copyright-holder**: Is the copyright holder the drafted LICENSE names right?
- **domain**: Are the proposed Domain topics all that apply?
- **status**: Is the proposed status right (active, maintenance or deprecated)?
- **tier**: Is the proposed tier right?
