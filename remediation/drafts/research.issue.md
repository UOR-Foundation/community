## Problem

UOR-Foundation/research does not yet meet the repository standards of UOR-Foundation/.github (STANDARDS.md and GOVERNANCE.md 6.1, 6.2 and 11), observed at `bfccda396aab` of `main`. It carries no tier tag. The uor-repo-tier app proposes Tier 4 (early experiments) from its use case, experiment: archived research code. Maintainers who record another tier tag change every requirement below; the change set is re-projected from it.

| Decision app | Observed | After the change set |
|---|---|---|
| uor-repo-files | conformant | conformant |
| uor-repo-protection | unobserved | conformant |
| uor-repo-standards | untagged | conformant |
| uor-repo-naming | nonconforming | blocked |

## Proposed Solution

### Repository settings an Organization Owner applies

- Block force pushes to the default branch
- Add topic uor
- Add topic uor-foundation
- Add topic tier-4-experimental
- Add topic archived: the repository is archived on GitHub, read-only as GOVERNANCE.md 11 defines Archived
- Add topic math: archived research code
- Add topic rust: GitHub's primary language is Rust, which Linguist names rust

Topics: `archived math rust tier-4-experimental uor uor-foundation`. The ruleset is `governance-6.2-t4` in `remediation/apply-settings.sh` of UOR-Foundation/community.
