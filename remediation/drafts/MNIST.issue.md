## Proposed Solution

### In a pull request

- Add LICENSE naming the LICENSE-APACHE and LICENSE-MIT the repository already carries, so the file GOVERNANCE.md 6.1 names states its license and documents the exception GOVERNANCE.md 13 asks for

### Repository settings an Organization Owner applies

- Require a pull request before merging to the default branch
- Require at least 1 approving review
- Require status checks to pass before merging
- Block force pushes to the default branch
- Add topic uor
- Add topic uor-foundation
- Add topic tier-3-presentation
- Add topic active: it is in normal development, its last commit 2026-10-14 (GOVERNANCE.md 11)
- Rename the repository to mnist
- Add topic computation: README: "The ONNX Model Zoo's int8 MNIST network as one LexLean model", a worked example
- Add topic latex: GitHub's primary language is TeX, which Linguist names latex

Topics: `active computation latex tier-3-presentation uor uor-foundation`. The ruleset is `governance-6.2-t3` in `remediation/apply-settings.sh` of UOR-Foundation/community.
